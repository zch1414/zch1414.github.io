# ZCH academic homepage

Static academic-style homepage for research and engineering work in embodied AI,
vision-language-action policies, ROS 2, MoveIt, and safe robot execution.

## Local preview

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.
